# Verde PWA v1.0

Offline-first PWA для ухода за домашними растениями.

## Запуск

Для разработки нужен любой локальный HTTPS/HTTP сервер. Например:

`python -m http.server 8080`

Откройте `http://localhost:8080/`.

Для установки на Android приложение должно быть опубликовано по HTTPS. В Chrome выберите «Добавить на главный экран / Установить приложение».

## Что есть

- 125+ растений в базе
- Сегодня / растения / календарь / ещё
- комнаты
- добавление растений
- полив одним нажатием
- история ухода
- заметки
- экспорт/импорт JSON
- offline cache через Service Worker
- PWA manifest
- запрос разрешения на уведомления

## Ограничение v1

Фоновая доставка уведомлений без сервера зависит от возможностей браузера/Android. В этой версии расписание хранится локально и уведомления разрешаются через Notification API. Надёжное долгосрочное фоновое планирование можно усилить на следующем техническом этапе, не меняя UX.
